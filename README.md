# Stella Desk

토키노 메리와 하나요 히요리의 방송을 모아 보는 Windows 앱입니다. 영상과 채팅을 함께 보고, 방송이 없을 때는 멤버 갤러리·치지직 클립·다시보기를 둘러볼 수 있습니다.

**[최신 설치 파일과 변경 내용](https://github.com/beugeumj01-lab/stella-desk-releases/releases/latest)**

이 저장소는 설치 파일과 업데이트를 배포하는 곳입니다. 치지직·네이버·스텔라이브가 만든 공식 앱은 아닙니다.

## 설치

Windows 10/11 64비트 PC에서 사용합니다. 릴리스의 **StellaDesk-버전-setup.exe**를 내려받아 실행하세요. 설치 후 바탕화면이나 시작 메뉴의 **Stella Desk**로 열 수 있습니다. 이전 ZIP 버전을 쓰고 있다면 먼저 앱을 종료한 뒤 설치해 주세요.

첫 설치 파일에는 Windows 코드 서명 인증서가 없습니다. Windows가 알 수 없는 게시자로 표시하거나 실행 경고를 보여줄 수 있습니다. 이 저장소의 릴리스에서 받은 파일인지 확인하세요. 앱의 업데이트 서명 검증은 Windows 게시자 인증과 별개입니다. 조직이나 PC의 보안 정책으로 차단되면 해당 정책을 우회하지 마세요.

## 로그인 유지

**설정 → 로그인과 저장 → 이 PC에서 로그인 유지**를 켜고 로그인합니다. 네이버 공식 로그인 화면에서도 **로그인 상태 유지**를 선택해 주세요. 설정을 바꾸면 다시 로그인해야 하며, 네이버 인증이 만료되거나 추가 확인이 필요하면 다시 로그인합니다.

비밀번호를 앱 설정에 저장하지 않습니다. 로그인 상태는 이 PC의 앱 전용 저장소에 보관하며 외부 브라우저의 로그인 정보를 가져오지 않습니다. **로그인 정보 지우기**로 앱의 저장 로그인을 지울 수 있습니다.

## 사용

- **라운지 / 시청 모드**로 화면을 전환합니다.
- 생방송·다시보기의 **채팅 접기 / 펼치기**로 영상 크기를 조절합니다.
- 영상 **···** 메뉴에서 음소거·화면 저장·미니 플레이어를 사용합니다.
- 클립·다시보기를 보관함에 저장하고 최근 시청에서 이어 볼 수 있습니다.
- **1080p 우선**은 PC에 설치된 네이버 공식 라이브 스트리밍 커넥터와 방송·계정 조건에 따라 동작합니다.
- 채팅은 읽기 전용입니다. 외부 서비스가 바뀌거나 요청을 제한하면 일부 기능이 일시적으로 동작하지 않을 수 있습니다.

## 업데이트

앱에서 새 버전을 확인하면 설정 버튼에 작은 표시가 생깁니다. **설정 → 앱 업데이트**에서 변경 내용을 읽고 **다운로드 → 재시작하여 업데이트**를 선택합니다. 자동 설치나 시청 중 강제 재시작은 하지 않습니다.

업데이트 전에 앱에 고정된 공개 키로 배포 서명을 확인하고 설치 파일의 크기·해시를 검사합니다. 설정·보관함·시청 기록은 업데이트 후에도 유지됩니다. 각 PC의 로그인 정보나 기록은 배포 파일에 포함되지 않습니다.
